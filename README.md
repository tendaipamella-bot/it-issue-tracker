#IT Issue Tracker
##Live Demo : view the App ( https://tendaipamella-bot.github.io/it-issue-tracker/)
#A responsive IT Issue Tracker built with HTML,CSS,JS and local storage.Log,track and resolve support tickets with filtering and search.
##FEATURES.
-CRUD Operations: Create,View,Update and delete IT issues.
-Filtering: Filter by Status, Priority and search by key word.
-Data Persistence: user browser local storage- no backend needed.
-Responsive UI; Works on desktop and mobile.

##How to use
-Fill out the "Log an issue" with tittle, reporter, priority.
-Click "Create Issue" to add it to the tracker
-Use filters and search to find issues quickly
-Update status to track progress from Active to Resolve.
